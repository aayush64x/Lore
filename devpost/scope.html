Lore

A personal CLI + local web UI that records what changed in your code, why you changed it, and walks you through the parts you didn't understand.

🔑 The Unique Kernel

The "I don't understand this yet" loop. Every code change starts as unreviewed. You come back, hit explain, get a plain-English walkthrough, and mark it learned when you actually get it. Lore isn't a changelog — it's a study list built from your real coding sessions.

The Core Loop

Who It's For

Students and self-taught developers who build with AI — pasting code from ChatGPT, working with Claude Code, moving fast. They ship things that work but don't always understand what they shipped.

"I know nothing can replace doing everything by yourself from scratch… Use AI while still learning."

POC Boundary

Now — The Proof of Concept

  • lore start — snapshot the project state (requires git)
  • lore stop — prompt, diff, AI summary, save session
  • lore ui — local web page with sessions, changes, explain, mark learned
  • Works on new and existing git repos
  • Non-git folder → Lore stops and tells you to initialize one
  • Everything flagged as "not understood" by default
Later
  • lore add — save a single file, line range, or pasted code with a note
  • "Why?" search in the web UI and lore why in the terminal
  • AI-highlighted concepts on top of the unreviewed list
  • Working without git
  • Accounts and cloud sync
Explicitly Cut
  • Capturing terminal output — session diffing catches what changed; transcript isn't needed
  • Live tracking of every file save — start/stop gives a clear, intentional boundary
  • Sending the whole project to AI — only the session's changes, not the entire codebase
  • Linked entries, AI agent export, graph view — interesting but not needed for the core loop
  • Quizzes and flashcards — Lore is a study list with walkthroughs, not a testing tool

The One-Minute Demo

  1. Run lore start
  2. Ask Claude Code to add or fix something
  3. Run lore stop, type what you were trying to do
  4. Open the web page — see the session summary and list of changes
  5. Open a change you don't understand, hit explain
  6. Read the step-by-step walkthrough
  7. Mark it as understood ✓
