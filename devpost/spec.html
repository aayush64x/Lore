Core Journey Through the System

lore start → Snapshot
  • Picocli parses command → checks git repo → checks no active session (filtered by project path)
  • GitService: temp GIT_INDEX_FILE → git add (non-ignored) → git write-tree → git commit-tree → git update-ref refs/lore/sessions/<id>
  • Temp index deleted. Working tree, staging area, hooks untouched.
  • SessionService: saves Session row (status=ACTIVE) to H2
  • Prints confirmation. No web server started.
lore stop → Diff + Parse + Summarize
  • Checks active session filtered by current project path
  • Prompts for one-line reason via stdin (empty allowed with warning)
  • GitService: creates stop snapshot (same process as start)
  • GitService: git diff-tree -r -p -M <start> <stop> (unified diff + rename detection)
  • DiffParser: splits patch into per-hunk changes; extracts @@ header values; skips lockfiles/generated; flags binaries
  • If no changes → "Nothing to save", discards session, cleans refs
  • AiService.summarize(): sends diffs to Bedrock → structured JSON (large sessions: file-by-file; very large files skipped with note; binaries listed not sent)
  • SessionService: saves changes, descriptions, summary to H2
  • Prints result line with counts
lore ui → Browse + Study
  • Boots Spring Boot with web server bound to 127.0.0.1 only
  • Serves bundled React frontend at /, REST API at /api
  • All queries filtered by current project path (global DB)
  • Session List: reason, date, files, progress per row; empty state; stale banner
  • Session Detail: summary, changes grouped by file, progress bar, unreviewed toggle
  • "Explain this" → POST /api/changes/{id}/explain → AiService numbers each diff line → model returns steps with diffLineStart/diffLineEnd → frontend highlights
  • Explanations cached in H2 — instant on return
  • "Mark as understood" toggle with undo

Components

CLI Layer

Implements prd.md > Session Recording, States and Boundaries
  • StartCommand: Spring headless → validate repo → check project session → snapshot → save
  • StopCommand: Spring headless → find project session → prompt → snapshot → diff → parse → summarize → save
  • UiCommand: Spring + web server (127.0.0.1) → serve frontend + API → open browser
  • LoreCli: help/status, stale session warning

Git Service YOU WRITE

Implements prd.md > Session Recording
  • Snapshot: temp GIT_INDEX_FILE → git add → write-tree → commit-tree → update-ref refs/lore/sessions/<id>
  • Diff: git diff-tree -r -p -M with rename detection → raw patch output
  • Cleanup: update-ref -d to remove refs for discarded sessions
  • Respects .gitignore; works with zero commits; doesn't touch staging/branches/hooks

Diff Parser YOU WRITE

Implements prd.md > Session Recording
  • Parses unified diff from git diff-tree -r -p -M
  • One Change per hunk (multiple hunks per file → multiple changes)
  • Extracts: file path, change type (ADDED/MODIFIED/DELETED/RENAMED), old_start/old_count/new_start/new_count from @@ headers
  • Renames: captures old + new file paths
  • Skips lockfiles/generated files; flags binary files (is_binary)
  • Assigns display_order for stable UI ordering

Session Service YOU WRITE

Implements prd.md > Session Recording, AI Summary, States and Boundaries
  • start(): validate repo → check project session → snapshot → persist
  • stop(): find project session → prompt → snapshot → diff → parse → summarize → persist
  • getStatus(): active session info + stale warning
  • All checks filter by current project path
  • Edge cases: already running, no session, no changes, not git, stale

AI Service YOU WRITE

Implements prd.md > AI Summary, Explain Walkthrough
  • Interface AiService + BedrockAiService
  • Summarize: diffs → session summary + per-change descriptions. Large sessions: file-by-file. Very large files skipped. Binaries listed not sent.
  • Explain: single diff with lines numbered 1, 2, 3… → overview, steps with diffLineStart/diffLineEnd, concepts
  • Converse API + tool-use for structured JSON output

Tests YOU WRITE

Verifies Git Service + Diff Parser
  • GitServiceTest: snapshot creates tree + ref, doesn't modify working tree/staging/HEAD, works with zero commits, cleanup deletes ref
  • DiffParserTest: single/multi-hunk, add/delete/modify/rename, @@ header parsing, binary detection, lockfile skipping, display_order
  • Hints: temp repos with @TempDir for git tests; string fixtures for parser tests

Failure Modes

AI call fails → Session/changes saved without summary/explanation. UI shows error + Retry. Everything else works.
Git missing or not a repo → lore start prints clear message and exits before doing anything.
No changes during session → lore stop prints "No changes since lore start. Nothing to save." Discards session, cleans up refs.

Key Decisions

Git snapshot: temp index + write-tree + commit-tree + update-refLearner-designed. Doesn't touch staging, branches, or hooks. Captures untracked files. Works with zero commits.
Per-hunk changes via DiffParsergit diff-tree -r -p -M with rename detection. One Change per hunk. Skips lockfiles, flags binaries.
Diff line numbering for explanationsLines numbered 1, 2, 3… when sent to AI. Steps reference diffLineStart/diffLineEnd. Frontend highlights by position.
H2 AUTO_SERVER=TRUEConcurrent access from CLI and web server in separate processes.
Web server bound to 127.0.0.1Local only — not exposed to the network.
Global DB, project-path filteringOne database in ~/.lore/, all queries filter by current project path.
Large session handlingOver size limit: summarize file by file. Very large files skipped with note. Binaries listed, not sent to AI.
TODO-driven core logic + unit testsLearner writes git ops, diff parsing, AI calls, session orchestration, and tests. Plumbing set up for them.
Future-proof without buildingData through /api, schema via Flyway, no process coupling. Auth/cloud deferred.
