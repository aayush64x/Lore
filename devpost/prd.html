Lore

A personal CLI + local web UI that records what changed in your code, summarizes it in plain English, and walks you through the parts you didn't understand.

The Core Journey

Screens & Surfaces

CLI

Four commands, terse output. The depth lives in the web UI.

  • lore start — snapshot & confirm
  • lore stop — prompt, diff, summarize, save
  • lore ui — launch web page
  • lore — help / session status

Session List (Web Home)

Project name at top. Sessions newest first.

  • Each row: reason, date/time, files changed, progress
  • Failed summary → "Summary failed" + Retry
  • Empty: "No sessions yet. Run lore start…"

Session Detail

Reason, date, plain-English summary at top.

  • Changes grouped by file, each with line range + description
  • Status: "Not understood yet" / "Understood"
  • Toggle: show unreviewed only
  • Progress bar for the session

Explain Walkthrough

Appears inline when "Explain this" is clicked on a change.

  • One-sentence overview
  • Step-by-step, each step highlights lines in the diff
  • "Concepts in this change" with one-line meanings
  • Cached — instant on return
  • "Mark as understood" button (undoable)

Features & Behavior

Session Recording
  • lore start snapshots via git, saves state on disk
  • lore stop prompts for reason, diffs, sends changes to AI, saves session
  • Session survives terminal close and restart — any terminal can stop it
  • Stale sessions get a reminder on any lore command and in the web UI
  • First session on a new project skips generated files and lockfiles
  • Git-ignored files (e.g. .env) are never sent to the AI
AI Summary
  • On stop: AI generates a session summary (few sentences) + one-line per change
  • Only session changes go to AI, never the whole project
  • Failure → "Summary failed" with Retry button, session preserved
Explain Walkthrough
  • One sentence overview → step-by-step with line highlighting → concepts list
  • Removed-only changes: explains what was removed and why it might matter
  • Cached after first generation — no re-calling AI
  • Failure → "Couldn't explain this change" with Retry
  • Fallback: if line highlighting isn't reliable, steps show line numbers as text
Progress Tracking
  • Everything starts as "Not understood yet"
  • "Mark as understood" button with undo
  • Session row shows progress (e.g. "3 of 7 understood")
  • Session detail has a progress bar and unreviewed-only toggle

States & Edge Cases

No sessions yet — "No sessions yet. Run lore start in your terminal to record your first one."
Session already running — "A session is already running since [time]. Run lore stop first." Running session untouched.
No active session — lore stop prints "No session is running." Nothing else happens.
Not a git repo — Lore stops and tells you to initialize git. Won't run git init.
No changes — lore stop prints "No changes since lore start. Nothing to save." and discards the session.
AI failure — Error message + Retry button. Session and data preserved.
Stale session — Any lore command and the web page remind you to stop it.
Persistence — Sessions, summaries, explanations, and progress persist on disk across restarts.

Product Decisions

Session mode over manual savesAgents write directly into the repo — no conscious paste moment to catch.
Everything starts unreviewedSimpler and more honest than AI guessing what you know.
Won't run git initLore doesn't make assumptions about your project setup.
API key in home folderPrevents accidental credential commits.
Explanations cachedNo re-calling AI for the same change. Instant on return.
Empty reason allowedDoesn't block you, but warns the summary will suffer.
Session state on diskSurvives terminal close and restart. Any terminal can stop it.

Scope Boundary

Building Now

  • lore start / lore stop / lore ui
  • Session list with progress, session detail with grouped changes
  • Diff view + explain walkthrough with line highlighting and concepts
  • Mark as understood / undo
  • AI summary and explain with retry on failure
  • One-time API key setup
  • Stale session reminders
Deferred
  • lore add — manual snapshots for files/ranges/pasted code
  • lore why + web search — searching across sessions
  • AI-highlighted concepts on the unreviewed list
  • Working without git
  • Accounts and cloud sync
Non-Goals
  • Capturing terminal output — diffing catches the result
  • Live file-save tracking — start/stop gives a clear boundary
  • Sending the whole project to AI — only session changes
  • Linked entries, agent export, graph view — not needed for core loop
  • Quizzes and flashcards — walkthroughs, not testing
